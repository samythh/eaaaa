# Wawancara

Folder ini memisahkan bukti mentah dari hasil olahan. Rekaman, foto, dan dokumen asli tidak boleh diedit atau ditimpa.

## Isi

- `01_Persiapan`: checklist, daftar data, daftar pertanyaan, dan briefing.
- `02_Rekaman_Asli`: audio/video asli dari lapangan.
- `03_Foto_Asli`: foto asli; keluarkan file yang memuat data sensitif dari bahan laporan.
- `04_Catatan_Anggota`: catatan individual, satu file per anggota.
- `05_Transkrip`: transkrip dan penanda waktu.
- `06_Dokumen_RS`: dokumen yang diberikan/diizinkan pihak RS beserta daftar sumber.
- `07_Hasil_Terstruktur`: hasil konsolidasi yang siap menjadi bahan laporan dan artefak.

## Batas privasi

Jangan menyimpan atau memasukkan ke laporan data pasien, resep, layar sistem berisi identitas pasien, dokumen keuangan/harga, informasi keamanan, alamat server, konfigurasi jaringan, atau foto wajah pasien/pengunjung.
